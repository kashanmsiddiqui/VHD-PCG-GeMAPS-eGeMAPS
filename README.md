# VHD-PCG-GeMAPS-eGeMAPS
This repository contains the MATLAB scripts and supporting codes used in the research paper “Phonocardiogram Classification Based on Features from the Geneva Minimalistic Acoustic Parameter Set”, currently under review at Scientific Reports. The repository includes code for Heart Sound (HS) dataset preparation, preprocessing, signal extraction, feature extraction, classifier training and evaluation, statistical analyses, and generation of the results reported in the manuscript. 

If you use whole or part(s) of these scripts/codes in your research, please cite both the associated manuscript and the software repository, as follows:-
